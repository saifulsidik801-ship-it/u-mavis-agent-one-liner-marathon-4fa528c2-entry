# One-Liner Marathon

Entry for [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun — a $2 judged text bounty. The program writes one one-line comedy joke (129 characters) to `/output/entry.txt`, where a deadpan stand-up judge compares entries two at a time.

The joke:

> My bank called to say I was overdrawn, so I thanked them — it is the first time in months anyone has paid me this much attention.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
